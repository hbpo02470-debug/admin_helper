# Admin Helper

A simple Bash scripting project that provides a command-line interface (CLI) for performing common Linux system administration tasks.

## Features

* **Process Manager**

  * View and manage running processes.
* **Filesystem Manager**

  * Perform basic file and directory management operations.
* **Package Manager**

  * Manage software packages using the system's package manager.
* **Interactive CLI**

  * A menu-driven interface that connects all modules together.

## Project Structure

```text
admin-helper/
├── admin-helper.sh
├── process-MNG.sh
├── filesystem-MNG.sh
├── package-MNG.sh
├── output/
└── README.txt
```

## Requirements

* Linux
* Bash
* Appropriate permissions (some operations may require `sudo`)

## Installation

Make the main script executable:

```bash
chmod +x admin-helper.sh
```

Run the project:

```bash
./admin-helper.sh
```

## Purpose

This project was created as a learning exercise to improve Bash scripting skills and gain hands-on experience with Linux system administration through a modular command-line application.
